# راسم الاهتزاز المهبطي

تطبيق محاكاة تفاعلي لراسم الاهتزاز المهبطي (الأوسيلوسكوب)، يتيح اختيار مصدر التيار (منوّب دراجة، بطارية 9V، مأخذ 220V)، وضبط مقابض الشاشة (ms/div، V/div)، وقراءة القياسات (Umax، Ueff، الدور الزمني T، التردد f) مباشرة على الشاشة الوامضة.

جزء من سلسلة محاكيات **PhysicLabDZ** التعليمية الموجهة للمنهاج الجزائري (الجيل الثاني).
